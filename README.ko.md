# Path of Idle In-Game Search

[English](README.md) · **한국어** · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md)

Path of Idle 게임 안에서 인벤토리·Warehouse·Vault 아이템을 검색하고 관리하는 비공식 Windows 모드입니다. 검색, 상세 툴팁, 게임 자체 이동 방식, 등급별 일괄 개봉, 0.1×~100× 배속을 하나의 불투명 오버레이에서 제공합니다.

## 주요 기능

- `F3` 또는 `Ctrl+F`로 게임 안에서 창 열기/닫기
- 이름, 등급, 부위, 레벨, 옵션, 세트, 보관 위치 통합 검색
- 공백 `AND`, `|` OR, `-단어` 제외, `"문구"` 일치 검색
- 검색 결과만 표시하고 일치한 글자 강조
- 좌우 방향키, Home, End, Backspace, Delete로 검색 커서 이동·편집
- 인벤토리와 Warehouse/Vault 결과 분리
- Rare, Legendary, Mythic, Set, Unique, 기타 등급 다중 선택 및 재클릭 해제
- 옵션과 세트 효과만 대상으로 검색
- 마우스를 올려 전체 설명, Legendary/Mythic/Unique 전체 옵션, 세트 적용 직업, 구성 장비와 단계별 효과 확인
- 검색 결과에서 인벤토리와 창고 사이 아이템 이동
- 게임 자체 보관 함수를 사용해 해금 상태와 등급 규칙에 따라 Warehouse 또는 Vault로 이동
- 장비 상자·룬 상자 등급 다중 선택 및 `이상` 조건 일괄 개봉
- 확인 생략, 공간이 허용하는 수량까지만 개봉, 새 장비 자동 보관 선택
- 검색·일괄 개봉·자동 빌드를 서로 분리된 페이지와 불투명 상세창으로 제공
- 기본 `장비+스킬 자동 빌드`에서 8개 장비 슬롯, 기본/액티브 스킬 조합, 전체 마스터리·포인트 레벨 벡터를 제한된 게임 자체 60초 미리보기로 함께 평가
- 선택부터 적용·검증까지 같은 빌드 계획 토큰과 정확한 레벨 벡터를 사용. 장비 8칸의 정확한 아이템, 학습·장비 부여 스킬, 변형, 저장·실효·상한 레벨, 사용·남은 포인트가 모두 일치해야 성공으로 표시
- 통합 적용 전체를 원자적으로 처리. 장비 이동·변환·초기화·배분·최종 검증 중 하나라도 실패하면 원래 장비와 특성, 이번 실행에서 쓴 Blood, 특성 진행 카운터, 저장된 스킬 선호를 복원하며, 가방이 가득 차 되돌릴 수 있는 임시 공간이 없으면 커밋 전에 안전하게 중단
- 게임 자체 Warehouse/Vault 분류 규칙을 따르고, 장착 완료 후 보관 아이템을 해금된 올바른 Vault 그룹으로 정리
- 직업·스킬 무기 규칙을 강제하고 게임 자체 Mythic 장착 한도를 적용
- 게임 능력치, 룬 옵션, 발동 세트 단계, 스킬 변형과 시너지로 약 60초 지속 성능을 비교. 안전하게 재현할 수 없는 런타임 조건은 임의 점수를 주지 않고 해당 경로를 제외하며, 실제 적·전투 AI까지 재현한 정확한 DPS가 아닌 제한된 추정치
- 장비가 부여한 스킬도 성능 계산에는 넣되 Shrine 학습 스킬 칸이나 특성 포인트는 사용하지 않음
- 자동, 물리, 원소, 화염, 냉기, 번개, 소환수, 출혈, 부식, 치명타, 지원, 방어 테마 선택. 자동 초점은 번역된 이름·설명 키워드가 아니라 게임 자체 스킬 피해 속성으로 결정
- 설정한 최대 횟수까지 Shrine의 정상 유료 변환으로 성능 목표에 맞는 스킬을 탐색. 초기화 비용과 고정·Alien 스킬을 보존하고 변환·초기화·배분 검증이 불완전하면 성공으로 표시하지 않음
- 한쪽만 다시 적용해야 할 때 쓰는 고급 `장비만 적용`과 `현재 장비로 스킬만` 복구 도구 제공. 기본 통합 최적화를 대신하지는 않음
- 단계 버튼 또는 직접 입력으로 0.1×~100× 배속 조절
- 모드 창에 포커스가 있을 때만 게임 키보드를 차단하고, 포인터가 포커스된 모드 창 위에 있을 때만 캐릭터 전환 휠 입력 차단
- 창 위치, 검색어, 필터, 배속, 언어, 일괄 개봉 설정 유지
- 게임 언어 자동 감지 또는 한국어·영어·중국어 간체·중국어 번체 수동 선택

아이템 이름과 설명은 게임이 현재 제공하는 현지화 데이터를 사용하며, 영문 이름도 검색 별칭으로 인식합니다.

## 설치 및 업데이트

1. [Releases](../../releases)에서 최신 `PathOfIdleInGameSearch-*.zip`을 받습니다.
2. ZIP을 완전히 풉니다.
3. Path of Idle을 종료합니다.
4. `install.bat`을 더블클릭합니다.
5. 게임을 실행하고 `F3`을 누릅니다.

설치기는 Steam의 게임 위치를 자동으로 찾습니다. BepInEx가 없을 때만 공식 `6.0.0-be.760` IL2CPP x64 빌드를 내려받아 SHA-256을 확인한 뒤 설치합니다. 기존 BepInEx가 있으면 그대로 사용하고 모드 DLL만 설치하거나 업데이트합니다.

배포용 Release DLL에는 모드 진단 로그와 디버그 심볼이 없습니다. BepInEx를 새로 설치할 때는 콘솔·디스크 로그도 기본으로 끄며, 기존 BepInEx가 있으면 그 설정은 유지합니다.

이전 버전 위에 다시 설치해도 `BepInEx/config/local.pathofidle.ingame-search.cfg`를 덮어쓰지 않으므로 사용자 설정이 유지됩니다.

## 조작법

| 기능 | 조작 |
| --- | --- |
| 창 열기/닫기 | `F3` 또는 `Ctrl+F` |
| 창 닫기 | `Esc` 또는 우측 상단 `×` |
| 언어 변경 | 제목 줄의 `AUTO·…`/언어 버튼 |
| 배속 단계 변경 | `−`, `+` |
| 배속 직접 입력 | 숫자 칸 클릭 → `0.1`~`100` 입력 → Enter 또는 `적용` |
| 정상 배속 복귀 | `1×` |
| 전체 아이템 설명 | 결과 행에 마우스 올리기 |
| 결과 페이지 이동 | 하단 버튼 또는 결과 영역에서 마우스 휠 |
| 자동 빌드 선택·실행 | `자동 빌드` 페이지에서 테마를 고른 뒤 기본 `장비+스킬 자동 빌드` 실행 |

검색과 개봉 등급은 여러 개를 동시에 선택할 수 있고, 선택된 등급을 다시 누르면 해제됩니다. 모두 해제하면 `전체`가 적용됩니다. 개봉의 `이상`을 켜면 선택한 등급 중 가장 낮은 등급부터 모든 상위 등급을 대상으로 합니다. `기타`는 등급 순서와 별개로 선택됩니다.

`WAREHOUSE` 탭에는 일반 Warehouse의 모든 페이지와 해금된 Vault 등급 그룹이 포함됩니다. 장비를 넣을 때 모드가 목적지를 임의로 판단하지 않고 게임 자체 `QuickMoveItemFromBagToStore`를 호출합니다.

일괄 개봉은 기본적으로 버튼을 두 번 눌러야 실행됩니다. `확인 생략`을 켜면 즉시 실행되므로 선택 등급, 남은 공간, `자동 창고` 설정을 먼저 확인하세요. 프레임마다 1개씩 열고 게임에서 실제 차감됐는지 확인합니다. 차감되지 않으면 일부 보상 중복을 막기 위해 재시도하지 않고 즉시 중단합니다. 필터는 보유한 상자 자체의 등급에 적용되며 랜덤 보상 등급을 조작하지 않습니다.

자동 빌드는 게임에서 현재 선택한 영웅에게 적용됩니다. 기본 동작은 무기 2칸과 나머지 6개 장비 슬롯, 기본/액티브 스킬 조합, 저장할 마스터리·포인트 레벨 전체를 하나의 계획으로 함께 탐색합니다. 현재 착용품도 후보에 유지합니다. 직업·스킬 무기 규칙, 해금된 Shrine 행, 고정·Alien 스킬, 마일스톤이 반영된 포인트 예산, 게임 자체 Mythic 한도와 보관 분류는 제약으로 지킵니다. 장비가 부여한 스킬은 부여된 레벨로 성능 미리보기에 포함하지만 Shrine 학습 스킬 칸과 특성 포인트는 소비하지 않습니다.

각 통합 후보는 게임 능력치, 모든 런타임 옵션, 룬, 부여 스킬, 스킬 변형, 실제 2세트·4세트 효과, 피해 속성, 쿨타임, 스킬 속도를 사용한 약 60초의 제한된 게임 자체 미리보기로 비교합니다. 자동 초점은 번역된 단어를 추측하지 않고 스킬의 게임 자체 피해 속성을 읽습니다. 안전하게 표현할 수 없는 런타임 발동이나 조건이 있으면 값을 꾸며 넣지 않고 해당 미리보기 경로를 제외합니다. 충분한 자원과 가동 시간을 가정한 추정치이며 적 방어, 이동 판단, 표적 패턴, 복잡한 발동 주기, 투사체 상호작용, 지속 피해 중첩, 소환수 동작, 전투 AI를 모두 재현한 정확한 DPS는 아닙니다.

한 테스트에서 약 20초에 끝난 기록은 해당 PC와 저장 데이터에서 관찰한 값일 뿐, 최적화 시간 보장이 아닙니다. 인벤토리 크기, 영웅, 스킬 후보에 따라 더 오래 걸릴 수 있습니다.

선택된 결과에는 하나의 계획 토큰이 붙습니다. 이 같은 토큰과 정확한 저장 레벨 벡터를 8부위 장착, 설정된 정상 Blood 유료 Shrine 변환·초기화, 포인트 배분, 최종 검증까지 그대로 사용합니다. 최종 검증은 장비 8칸의 정확한 아이템, 학습 스킬, 최종 장비에서 다시 계산한 장비 부여 스킬, 변형, 저장·실효·상한 레벨, 사용·남은 포인트를 모두 확인하며, 지원하지 못하는 상태나 불완전한 적용은 성공으로 표시하지 않습니다. 통합 적용 전체가 하나의 원자적 작업이므로 장비 이동 후 단계에서 실패해도 원래 장비와 특성 행을 되돌리고, 이번 실행에서 사용한 Blood를 환불하며, 특성 진행 카운터와 저장된 기본 스킬·스킬 선호를 복원한 뒤 복구 결과까지 검증합니다. 실행에는 같은 버튼을 한 번 더 눌러야 합니다.

고급 `장비만 적용`과 `현재 장비로 스킬만`은 한쪽만 다시 적용할 때 쓰는 복구 도구입니다. 다른 한쪽을 고정하므로 기본 통합 최적화와 같은 결과를 보장하지 않습니다.

100×처럼 높은 배속은 짧은 애니메이션이나 타이머를 건너뛸 수 있으므로 작업 후 `1×`로 되돌리는 것을 권장합니다.

## 제거

게임을 종료하고 `uninstall.bat`을 실행합니다. 이 모드 DLL만 제거하며 BepInEx, 다른 모드, 사용자 설정은 유지합니다.

## 직접 빌드

.NET 6 SDK 이상이 필요합니다. BepInEx 설치 후 게임을 한 번 실행해 interop 어셈블리를 만든 다음 게임을 종료하고 `scripts\build.ps1`을 실행하세요. 로컬 게임 어셈블리만 참조하며 게임 파일은 저장소에 포함하지 않습니다.

## 호환성

- Windows x64
- Steam 버전 Path of Idle
- Unity IL2CPP / BepInEx 6

게임 업데이트로 내부 데이터 구조가 바뀌면 모드 업데이트가 필요할 수 있습니다.

이 프로젝트는 Path of Idle 또는 BepInEx 제작사와 관련 없는 비공식 팬 프로젝트입니다. 중요한 세이브는 미리 백업해 두는 것을 권장합니다.
