# Path of Idle In-Game Search

Path of Idle 안에서 인벤토리·Warehouse·Vault 아이템을 검색하고 관리하는 비공식 Windows 모드입니다. 검색, 상세 툴팁, 게임 규칙을 따르는 아이템 이동, 일괄 상자 개봉, 0.1×~100× 배속을 하나의 불투명 오버레이에서 제공합니다.

> Unofficial in-game inventory, Warehouse, and Vault search/management overlay for Path of Idle. The UI supports Korean, English, Simplified Chinese, and Traditional Chinese.

## 주요 기능

- `F3` 또는 `Ctrl+F`로 게임 안에서 창 열기/닫기
- 이름, 등급, 부위, 레벨, 옵션, 세트, 보관 위치 통합 검색
- 공백 `AND`, `|` OR, `-단어` 제외, `"문구"` 일치 검색
- 검색 결과만 표시하고 일치한 글자를 강조
- 인벤토리와 Warehouse/Vault 결과를 분리해 표시
- Rare, Legendary, Mythic, Set, Unique 등급 다중 선택 필터(다시 누르면 해제)와 `옵션만 검색`
- 마우스를 올리면 아이템 설명, 모든 옵션, 세트 구성 장비와 단계별 세트 효과 표시
- 결과에서 인벤토리 ↔ 창고 이동
- 입고 시 게임 자체 자동 분류 함수를 사용해 해금 상태와 등급 규칙에 따라 Warehouse 또는 Vault로 이동
- 장비 상자·룬 상자의 개봉 등급 다중 선택 및 `선택 등급 이상` 필터
- 장비 상자·룬 상자 모두 열기, 확인 생략 선택, 공간이 허용하는 수량까지만 개봉
- 장비 상자 개봉 결과를 게임 규칙에 따라 자동 보관하는 선택 기능
- 단계 버튼과 직접 입력을 모두 지원하는 `0.1×~100×` 게임 배속
- 오버레이 영역만 게임 클릭·휠 입력을 차단하며 바깥 게임 UI는 정상 동작
- 창 위치, 검색어, 필터, 배속, 언어, 일괄 개봉 설정 유지
- 게임 언어 자동 감지 또는 `AUTO → 한국어 → English → 简体中文 → 繁體中文` 수동 전환

아이템 이름과 설명은 게임이 현재 제공하는 현지화 데이터를 사용하며, 영문 이름도 검색 별칭으로 함께 인식합니다.

## 설치 및 업데이트

1. [Releases](../../releases)에서 최신 `PathOfIdleInGameSearch-*.zip`을 받습니다.
2. ZIP을 완전히 풉니다.
3. Path of Idle을 종료합니다.
4. `install.bat`을 더블클릭합니다.
5. 게임을 실행하고 `F3`을 누릅니다.

설치기는 Steam의 Path of Idle 설치 위치를 자동으로 찾습니다. BepInEx가 없을 때만 공식 `6.0.0-be.760` IL2CPP x64 빌드를 내려받고 SHA-256을 검증한 뒤 설치합니다. 이미 BepInEx가 있으면 그대로 사용하며 모드 DLL만 설치 또는 업데이트합니다.

기존 버전 위에 다시 설치해도 `BepInEx/config/local.pathofidle.ingame-search.cfg`는 덮어쓰지 않으므로 검색·창 위치·배속 같은 사용자 설정이 유지됩니다.

## 사용법

| 기능 | 조작 |
| --- | --- |
| 창 열기/닫기 | `F3` 또는 `Ctrl+F` |
| 창 닫기 | `Esc` 또는 우측 상단 `×` |
| 언어 변경 | 제목 줄의 `AUTO·…`/언어 버튼 |
| 배속 단계 변경 | `−`, `+` |
| 배속 직접 입력 | 배속 숫자 칸 클릭 → `0.1`~`100` 입력 → Enter 또는 `적용` |
| 정상 배속 복귀 | `1×` |
| 상세 설명 | 결과 행에 마우스 올리기 |
| 결과 페이지 이동 | 아래 버튼 또는 결과 영역에서 휠 |

`WAREHOUSE` 탭은 일반 창고의 모든 페이지와 Vault의 해금된 품질 그룹을 함께 검색합니다. 아이템 입고는 모드가 등급을 임의로 판단하지 않고 게임 자체 `QuickMoveItemFromBagToStore` 절차를 사용합니다.

검색 Tier와 개봉 Tier는 여러 등급을 동시에 선택할 수 있으며, 선택된 등급을 다시 누르면 해제됩니다. 아무 등급도 선택하지 않으면 전체가 대상입니다. 개봉 Tier의 `이상`을 켜면 선택한 등급 중 가장 낮은 등급부터 상위 등급까지 대상으로 잡습니다. `기타`는 등급 순서 밖의 아이템을 뜻하며 별도로 선택됩니다.

일괄 개봉은 기본적으로 같은 버튼을 두 번 눌러야 실행됩니다. `확인 생략`을 켜면 한 번에 실행되므로 버튼을 누르기 전에 남은 공간과 `자동 창고` 설정을 확인하세요. 공간이 부족하면 가능한 수량까지만 열고 나머지는 그대로 남깁니다. 필터는 보유한 상자 자체의 등급에 적용되며, 랜덤으로 나오는 보상의 등급을 조작하지는 않습니다.

100×처럼 높은 배속은 애니메이션이나 짧은 타이머를 건너뛸 수 있습니다. 필요한 작업이 끝나면 `1×`로 되돌리는 것을 권장합니다.

## 제거

게임을 종료하고 `uninstall.bat`을 실행합니다. 이 모드 DLL만 제거하며 BepInEx, 다른 모드, 사용자 설정은 유지합니다.

## 직접 빌드

.NET 6 SDK 이상이 필요합니다. BepInEx 설치 후 게임을 한 번 실행해 interop 파일을 만든 다음 `scripts\build.ps1`을 실행하세요. 빌드 시 로컬에 설치된 게임 어셈블리만 참조하며 게임 파일은 저장소에 포함하지 않습니다.

## 호환성

- Windows x64 / Steam Path of Idle
- Unity IL2CPP / BepInEx 6
- 게임 업데이트로 내부 데이터 구조가 바뀌면 모드 업데이트가 필요할 수 있습니다.

이 프로젝트는 Path of Idle 또는 BepInEx 제작사와 관련 없는 팬 프로젝트입니다. 중요한 세이브는 별도로 백업해 두는 것을 권장합니다.
