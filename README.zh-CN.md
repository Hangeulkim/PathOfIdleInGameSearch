# Path of Idle In-Game Search

[English](README.md) · [한국어](README.ko.md) · **简体中文** · [繁體中文](README.zh-TW.md)

一款非官方 Windows 模组，可在 Path of Idle 游戏内搜索和管理背包、Warehouse 与 Vault 中的物品。它通过一个不透明的覆盖窗口提供搜索、完整提示、游戏原生物品移动、按品质批量开启以及 0.1×–100× 速度控制。

## 功能

- 使用 `F3` 或 `Ctrl+F` 打开或关闭窗口
- 按名称、品质、部位、等级、词缀、套装和存放位置搜索
- 空格表示 `AND`，`|` 表示 OR，`-词语` 表示排除，`"短语"` 表示完整短语
- 仅显示匹配物品并高亮匹配文字
- 分别查看背包与 Warehouse/Vault 结果
- 多选 Rare、Legendary、Mythic、Set、Unique 和其他品质；再次点击即可取消
- 仅搜索词缀和套装效果
- 悬停查看完整说明、全部词缀、套装部件及各阶段套装效果
- 直接从搜索结果在背包与仓库之间移动物品
- 使用游戏自身的存储逻辑，按已解锁状态和品质规则移入 Warehouse 或 Vault
- 按品质多选批量开启装备箱和符文箱，并支持“及以上”模式
- 可跳过二次确认、在空间不足时只开启可容纳数量，并自动存放新装备
- 将当前装备也纳入候选，联合优化两把武器与其他六个部位，共八个装备槽
- 强制检查职业与当前技能的武器需求，并综合技能专属效果、实际生效的套装阶段及游戏计算出的伤害、生存和辅助属性
- 使用预设按钮或直接输入，将游戏速度调整为 0.1×–100×
- 仅在模组窗口获得焦点时阻止游戏键盘；角色切换滚轮也只在鼠标位于已聚焦窗口内时阻止
- 保存窗口位置、搜索词、筛选、速度、语言及批量开启设置
- 自动跟随游戏语言，或手动选择韩语、英语、简体中文和繁体中文

物品名称和说明使用游戏当前提供的本地化文本，英文物品名也会作为搜索别名加入索引。

## 安装与更新

1. 从 [Releases](../../releases) 下载最新的 `PathOfIdleInGameSearch-*.zip`。
2. 完整解压 ZIP。
3. 关闭 Path of Idle。
4. 双击 `install.bat`。
5. 启动游戏并按 `F3`。

安装程序会自动查找 Steam 游戏目录。若未安装 BepInEx，它只会下载固定的官方 `6.0.0-be.760` IL2CPP x64 版本，并在安装前验证 SHA-256。若已安装 BepInEx，则会继续使用现有安装，仅安装或更新本模组 DLL。

覆盖旧版本重新安装不会改写 `BepInEx/config/local.pathofidle.ingame-search.cfg`，因此用户设置会被保留。

## 操作

| 操作 | 按键或按钮 |
| --- | --- |
| 打开或关闭窗口 | `F3` 或 `Ctrl+F` |
| 关闭窗口 | `Esc` 或右上角 `×` |
| 更改界面语言 | 标题栏中的 `AUTO·…`/语言按钮 |
| 分级调整速度 | `−` 和 `+` |
| 输入自定义速度 | 点击速度框，输入 `0.1`–`100`，然后按 Enter 或 `应用` |
| 恢复正常速度 | `1×` |
| 查看完整物品详情 | 将鼠标悬停在结果行上 |
| 切换结果页 | 底部按钮，或在结果区域使用滚轮 |

搜索品质和开启品质都支持多选。再次点击已选择的品质即可取消；全部取消后会恢复为“全部”。开启“及以上”后，将从所选品质中最低的一个开始，包含所有更高品质。“其他”不参与品质排序，可单独选择。

`WAREHOUSE` 标签包含普通 Warehouse 的所有页面及已解锁的 Vault 品质组。存放装备时，模组会调用游戏原生的 `QuickMoveItemFromBagToStore`，而不是自行猜测目标位置。

批量开启默认需要点击同一按钮两次。启用“跳过确认”后会立即执行，因此请先检查所选品质、剩余空间和“自动入库”设置。空间不足时，只会开启能够容纳的数量，其余保留。筛选针对你所持有箱子的品质，不会修改随机奖励的品质。

`100×` 等极高速度可能跳过较短的动画或计时器。完成操作后建议恢复为 `1×`。

## 卸载

关闭游戏并运行 `uninstall.bat`。它只删除本模组 DLL，不会删除 BepInEx、其他模组或用户配置文件。

## 从源码构建

需要 .NET 6 SDK 或更高版本。安装 BepInEx 后运行一次游戏以生成 interop 程序集，关闭游戏，再运行 `scripts\build.ps1`。构建过程只引用本地安装的游戏程序集，仓库中不包含游戏文件。

## 兼容性

- Windows x64
- Steam 版 Path of Idle
- Unity IL2CPP 与 BepInEx 6

若游戏更新改变内部数据结构，模组可能需要同步更新。

本项目是非官方粉丝作品，与 Path of Idle 或 BepInEx 的开发者无关。使用非官方模组前，建议备份重要存档。
